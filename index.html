The review queue: three structures and a hybrid

Each option arranges the same invented household's eleven decisions and two ideas differently. This round is about structure and flow, not looks: greyscale on purpose, with one colour reserved for “act now”. Everything is clickable: download this file and open it in a browser. Decide an item (it leaves, with Undo), open one, snooze one. On desktop, j/k move, a does the main action and s snoozes.

Out of scope this round: visual identity. There is no palette, type or brand yet, because the product name isn't settled. Greyscale is deliberate, and the one accent colour does one job only: it marks things that cost something if they wait.
