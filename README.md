# Review queue: structure options (#17)

Mid-fidelity mockups for the review queue proposed in #17. This round covers structure and flow only. It is greyscale on purpose, with no visual identity until the product name is settled. Every figure belongs to an invented household.

- `index.html` is the clickable board: four options, each on phone (Home, the queue, one opened item) and desktop (list and detail). Download it and open it in a browser. In the desktop view, j/k move, a does the main action and s snoozes.
- `screenshots/` holds a phone and a desktop screenshot of each option.

| Option | Structure |
| --- | --- |
| D · Hybrid | A's time-spine queue, with B's Home card (one chip per kind with its count) |
| A · By when | An agenda on a time spine with a "now" line; items without a deadline sit in a band below it |
| B · By kind | One shelf per kind, each with a count and its own bulk action |
| C · By stakes | One list in four tiers, as #17 proposes, with each row's main action inline |

This branch holds only these files. It is not meant to be merged.
